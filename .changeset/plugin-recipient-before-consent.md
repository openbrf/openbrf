Refuse a plugin install whose answer about where the plugin sends personal data
the record of processors would refuse, before the consent is recorded.

An independent controller with no reason given, a personal identity number in
the recipient or the note, or an agreement said to be in place without a date or
the terms art. 28(3) requires used to be refused only after the consent row was
written. An install from the command-line tool or a script then left a consent
behind with no install, no processing activity in the record of processing and
no classification in the record of processors. The web screen was not affected,
because it checks the same rules before it sends the answer.
