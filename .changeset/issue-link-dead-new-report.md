The page a reporter's private link shows when it no longer opens an issue now
also says how to make a new report, on the association's website. A link to an
issue closed more than 30 days ago used to say only to contact the association.
Every link that opens nothing still gets the same page, so the added sentence
does not tell a closed issue from an expired or withdrawn link.
