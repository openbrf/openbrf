The page a reporter's private link shows when it no longer opens an issue now
also says that, if the association's website takes new reports, a new report can
be made there. A link to an issue closed more than 30 days ago used to say only
to contact the association. The sentence is conditional because the page cannot
tell whether the website has a report form. Every link that opens nothing still
gets the same page, so the added sentence does not tell a closed issue from an
expired or withdrawn link.
