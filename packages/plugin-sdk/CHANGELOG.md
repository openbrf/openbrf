# @openbrf/plugin-sdk

## 1.0.0

The first published version. It implements version 1 of the
[plugin contract](https://github.com/openbrf/openbrf/blob/main/docs/plugin-contract.md):
the manifest schema, the permission set and the personal data categories, the
action and settings schemas, the host service interfaces, the catalog index
schema, and `pluginPackageProblems`, the check a plugin package passes before it
is listed.
