# @openbrf/theme-tools

## 1.0.0

The first published version, for version 1.0.0 of the
[token contract](https://github.com/openbrf/openbrf/blob/main/docs/theme-contract.md):
the theme manifest schema, the archive reader and writer, inheritance, the view
variants, the lint an instance runs at install, and `lintThemePackage`, which
runs that lint on a packed theme.
